# AI 实战训练营｜课程课件

`Codex × WorkBuddy × Grokbot` 两天一夜线下实战课的 HTML 课件。

## 打开

直接打开 `ai-practice-bootcamp-v3.html`（当前版本，56 页），或使用本地静态服务器访问。历史版本：`ai-practice-bootcamp-v2.html`（26 页）、`ai-practice-bootcamp.html`（v1）。

快捷键：`← / →` 翻页，`N` 显示讲稿，`F` 全屏，可直接用浏览器打印导出 PDF。

## 作业包

`作业包/`：五个现场作业的作业单、模板、示例资料和网站模板，开课当天发给学员（`讲师/` 子文件夹除外）。每个作业的图文教程在 `作业包/教程/`（浏览器打开 `index.html`），附一份用示例资料完整做完五个作业的业务文件夹。课后选做的进阶作业「把知识库做成客服机器人」在 `作业包/进阶-知识库客服/`。说明见 `作业包/README.md`，课前清单见 `作业包/学员课前清单.md`。

## 课程体系

- `course-system-v3.md`：v3 课程体系（主线「一个业务，四个作业」、时间表、工具分工、作业分层、课前准备），以此为准
- `lecture-outline.md`、`ai-course-deck-outline-script-v1.md`：v1 大纲与讲稿，仅作归档
