# AI 实战训练营｜课程课件

`Codex × WorkBuddy × Grokbot` 两天一夜线下实战课的 HTML 课件。

## 打开

直接打开 `ai-practice-bootcamp-v2.html`（新版，26 页），或使用本地静态服务器访问。旧版为 `ai-practice-bootcamp.html`。

新版快捷键：`← / →` 翻页，`N` 显示讲稿，`F` 全屏，可直接用浏览器打印导出 PDF。

## 演示

- `← / →`、空格：翻页
- 手机左右滑动：翻页
- `E`：进入文字编辑
- 页面右上角：保存修改、导出 HTML
