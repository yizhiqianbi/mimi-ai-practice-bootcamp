# AI 实战训练营｜学员课前清单

开课前 1 周有一次 **30 分钟线上装机会**，逐项检查下面这些。现场不再花时间注册和排查。

**过关标准**：三个工具（Codex、WorkBuddy、Grokbot）**各发一句话有回应**；测试邮箱地址**已发给助教**；资料文件夹**已备好**。

## 设备

- [ ] 笔记本电脑（Mac / Windows），有管理员权限，能装软件
- [ ] 手机：测试网站、接收线索通知
- [ ] 网络：能稳定访问 OpenAI 和海外服务（企业请用合规跨境专线）

## 账号

以讲师最终通知的平台为准。

- [ ] **Codex**：装好 ChatGPT 桌面应用，左上角能切到 Codex，发一句话有回应
- [ ] **WorkBuddy**：桌面客户端，微信扫码登录
- [ ] **Grokbot**：装好 Grok Bot 应用，用 Cursor 账号登录
- [ ] **测试邮箱**：新注册一个 QQ 邮箱，在 设置 → 账号 → POP3/IMAP/SMTP 服务 里开启 IMAP，记下授权码。**不要用公司邮箱**。注册好后把地址发给助教，讲师会往里面发 13 封练习邮件
- [ ] **企业微信**：能建群、能加群机器人
- [ ] **GitHub** 账号
- [ ] **静态托管平台**账号（讲师通知用哪个）
- [ ] **腾讯智影**账号：打开 zenvideo.qq.com，微信扫码登录即可。客户在海外、要做英文视频的，另注册 **HeyGen**（heygen.com，需要能访问海外网站）
- [ ] （进阶）自有域名

## 资料

整个课程都围绕**你自己的一个真实业务**来做。

- [ ] 业务介绍，2–3 个真实案例（可以脱敏，客户名写成「某连锁餐饮品牌」）
- [ ] 一个业务资料文件夹，约 20–50 个文件：报价单、产品介绍、合同模板、客户常见问题、会议记录……**只带可以公开或已经脱敏的**，乱一点没关系，作业一就是整理它
- [ ] Logo、产品图或门店照片
- [ ] 一个近期真要讲的主题（给客户的方案、招商会、内部分享都行）
- [ ] （进阶）约 2 分钟正面说话视频（1080p，单人正对镜头，房间安静），用来做本人数字分身，**开课前 2 天**上传到数字人平台；HeyGen 还要本人用摄像头录一段同意声明

没带资料也没关系，讲师准备了一套虚构公司的示例资料。

## 开课第一天会发给你

一个「作业包」文件夹：工作区模板、每个作业的作业单和模板。
