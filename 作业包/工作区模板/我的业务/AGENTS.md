# 文件夹

- `资料/`：原始文件的副本，只读，不改、不删、不移动
- `知识库/`：作业一整理后的资料、总索引、FAQ素材.md
- `产出/`：PPT、海报、口播稿、发布文案
- `assets/`：Logo、产品图、主视觉、brand.md（品牌色和字体）
- `site/`：作业四的网站
- `.agents/skills/`：Skill，一个文件夹一个

# 规矩

- 全部用中文输出
- 数字、价格、案例必须注明出处（文件名 + 位置）；找不到出处就写「待确认」，不要编
- 事实、推断、待确认分开写
- 不确定就先问我
- 动手前先给大纲或中间结果，我确认后再成稿
- 文件名：`日期_主题_版本`，例如 `20261028_报价单_v2.xlsx`
- 对外发送的东西（邮件、帖子、表单回复）只起草，不发送
