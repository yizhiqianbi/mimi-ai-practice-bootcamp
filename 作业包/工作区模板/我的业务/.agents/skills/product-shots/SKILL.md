# 产品套图（WorkBuddy 或 Codex + LibTV）

## 一句话调用

> 用 product-shots 给 素材/产品/____.jpg 出一套 1688 主图和场景图

## 需要

- 和 `libtv-ad` 一样：LibTV 账号、`libtv-skills`、环境变量 `LIBTV_ACCESS_KEY`
- 产品手册里的尺寸、材质、卖点（`知识库/`）

## 输入

- 产品图：1–3 张，正面最好是白底
- 平台：____（1688 / 淘宝 / 亚马逊 / 独立站），决定尺寸和张数
- 卖点：从知识库里挑 3 个，或者我直接给

## 步骤

1. **列图单**：按平台列出要出的每一张：用途、尺寸、场景描述、上面要放的文字。默认 6 张：主图、使用场景 2 张、细节特写、尺寸图、卖点图。**给我看图单，等我确认。**
2. **生成场景**：上传产品图作参考，让 LibTV 只生成「场景和光线」，产品本身保持参考图的样子。每张出 2 个候选
3. **逐张核对**：把每张候选和原图并排看：结构、比例、颜色、Logo、配件数量。不一致的淘汰；两轮都不行的那张改用实拍或纯色背景
4. **加字**：尺寸、卖点、价格这些文字不让 AI 画，用 HTML 按品牌色排在图上导出 PNG，数字全部来自产品手册
5. 按平台尺寸导出，文件名带序号和用途

## 规则

- 产品不能被 AI 改样子；核对不过的图不交
- 尺寸、材质、认证只写产品手册里有的
- 场景里不出现别人的品牌、商标和真人面孔
- 平台要求标注 AI 生成的，按平台规则标

## 输出

- `产出/套图/日期_产品名/01_主图.png` … `06_卖点.png`
- `产出/套图/日期_产品名/图单.md`：每张的用途、尺寸、核对结果

## 验收

- [ ] 每张图里的产品和原图对得上
- [ ] 每个数字都能在产品手册里找到
- [ ] 尺寸符合平台要求
