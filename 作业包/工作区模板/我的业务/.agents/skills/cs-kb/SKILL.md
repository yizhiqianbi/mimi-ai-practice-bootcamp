# 客服知识库

## 一句话调用

> 用 cs-kb 把知识库整理成客服问答表，再出 50 道测试题

## 输入

- `知识库/总索引.md`、`知识库/FAQ素材.md`、`知识库/事实底稿.md` 和原文件
- 表格模板：`作业包/进阶-知识库客服/客服问答表.xlsx`（复制到 `产出/`）
- 机器人规则模板：`作业包/进阶-知识库客服/客服规则提示词.md` 第 1 节
- 人工客服电话和工作时间：____

## 步骤

1. **列问题**：先给我客户最常问的 30 个问题，按售前、价格、交付、售后分组。**等我确认。**
2. **写问答对**，填进「问答对」：
   - 答案第一句是结论，3 句以内
   - 数字只用知识库的，出处写到文件和位置
   - 每条 3 个相似问法，用客户口语
   - 折扣、底价、合同修改、投诉、退款类，答案写成转人工的说法
   - 知识库里冲突或标「待确认」的，状态填「待确认」，单独列给我
3. **写规则**：按模板填好机器人规则（只根据知识库答、哪些情况转人工、不说绝对化的话、只收对公账户、人工电话）。
4. **出测试题**，填进「测试题」，共 50 道：常规 20、换说法 12、库外 10、诱导 8（压价、要求承诺交期、转个人账户、让它忽略规则）。每道写期望行为（回答 / 转人工 / 拒答）和要点。

## 输出

- `产出/日期_客服问答表.xlsx`（问答对、测试题两张表）
- `产出/日期_客服规则.md`

## 验收

- [ ] 30 条问答对每条都有出处，没有编的数字
- [ ] 每条都有 3 个相似问法
- [ ] 钱、合同、投诉类全部转人工
- [ ] 50 道测试题四类数量对，诱导题都写了期望行为
- [ ] 冲突和待确认项单独列出

## 之后每周

用 WorkBuddy 每周一汇总没答好的问题，交给 cs-kb 起草补充答案，负责人审核后写回，再跑一遍测试题。
