# 通话复盘（WorkBuddy / 通义听悟 + Codex）

## 一句话调用

> 用 call-coach 复盘 素材/录音/____.m4a

## 需要

- 转写：通义听悟或飞书妙记导出的文字稿（带说话人和时间），或者让 Codex 用本机 `faster-whisper` 转
- `知识库/` 里的销售话术、产品价格、FAQ

## 输入

- 录音或转写稿：`素材/录音/`
- 这通电话的目标：____（例：约到上门量尺）

## 步骤

1. **转写**：分清哪句是我方、哪句是客户，存 `产出/日期_转写_客户.md`
2. **客户信息卡**：需求（人数、品类、风格）、预算、时间、决策人、顾虑、竞品，每项后面标原话出处（第几分钟）；没聊到的写「没问到」
3. **打分**：五项各 1–5 分，每项一句理由：需求挖掘、产品讲解、异议处理、推进下一步、合规（有没有乱承诺价格和交期）
4. **改三句**：挑三句最可惜的原话，写「原话 → 更好的说法 → 为什么」，说法要符合知识库里的事实
5. **下一步**：建议的下一步 + 一条发给客户的跟进消息草稿
6. WorkBuddy 把信息卡和三句改法推给这个销售；分数只发给我

## 规则

- 录音要提前告知对方；没告知的录音不处理
- 只评话术，不评价人
- 跟进消息只起草，不发送
- 客户信息不出公司

## 输出

- `产出/日期_通话复盘_客户.md`：信息卡、打分、三句改法、跟进草稿

## 验收

- [ ] 信息卡每项都有出处或「没问到」
- [ ] 三句改法里的事实都能在知识库找到
- [ ] 跟进消息没有被发出
