# 60 秒口播成片（Codex + 配音 + 浏览器渲染 + 剪映）

## 一句话调用

> 用 talk-video 给我的业务做一条 60 秒口播视频，讲给「____」听，最后让他们「____」

## 需要（第一次用装一次，Codex 会帮你装）

- Python 3.9+、ffmpeg（Windows：`winget install Gyan.FFmpeg`；Mac：`brew install ffmpeg`）
- `pip install playwright edge-tts pillow`，然后 `python -m playwright install chromium`
- 想用自己的声音：每句录一条，放进 `录音/s1.m4a`、`录音/s2.m4a`……，脚本优先用录音，不再合成
- 要剪映草稿：再装 `jianying-draft` 那一套（剪映专业版 + `pip install pyJianYingDraft`）

脚本：`.agents/skills/talk-video/scripts/talkvideo.py`（下面写作 `talkvideo.py`）

## 输入

- `业务卡片.md`、`知识库/`，或者一个已上线的官网网址：事实只能从这里来
- 讲给谁、希望他们做什么（一个动作，最好指向作业四的网站）
- 素材：`素材/` 里的产品图（透明底最好）、现场照片、Logo；BGM 只用有授权的（自己宣传片的原声最稳）
- 品牌色：主色、底色、文字色；没有就用模板默认

## 步骤

### 1 · 事实底稿

读输入，写 `产出/日期_事实底稿.md`：一行一个能上口播的事实，写**原文和出处**。资料里没有的写进「没写、不能说」一栏（客户案例、价格、认证、排名……），**不补编**。

### 2 · 3 个钩子 → 停，等我选

每个 20 字以内，三种写法各一个：反常识、具体数字（必须在底稿里有出处）、点名处境。写清字数和出处，推荐一个并说理由。

### 3 · 五段口播稿 → 停，等我确认

| 段 | 时长 | 写什么 |
|---|---|---|
| 钩子 | 0–3 秒 | 选中的那句 |
| 冲突 | 3–15 秒 | 客户现在的处境和痛 |
| 证据 | 15–35 秒 | 真实案例带数字；没有案例就用产能、参数这类硬数字，并标「待提供：客户案例」 |
| 转折 | 35–52 秒 | 所以怎么做：你的方法、条件、承诺 |
| 行动 | 52–60 秒 | **只给一个动作** |

稿子直接写进 `口播.json` 的 `sentences`（一句一条，见下面「口播.json 怎么写」），同时给我一张五段表看。

- 每句一个 `src`（出处）；证据、转折段没有出处的句子不许留
- **数字写 `say`（读法）**：`15 天`→`十五天`、`6000BTU`→`六千 BTU`、`C18`→`C 十八`；网址只上屏不读
- 屏幕上要突出的词用 `[ ]` 括起来，字幕里会标成主色

### 4 · 配音

```
python talkvideo.py voice 口播.json
```

逐句合成（默认 `zh-CN-YunyangNeural`，语速 `+8%`），或用 `录音/` 里的本人录音。打印每句时长。

### 5 · 分镜 → 停，等我看总览

在 `口播.json` 的 `scenes` 里给每个镜头排版块（一个镜头只说一件事：一张素材 + 一行大字），然后：

```
python talkvideo.py preview 口播.json
```

把 `产出/名称_镜头总览.jpg` 给我看。

### 6 · 自查，直到通过

```
python talkvideo.py check 口播.json
```

脚本会挡住：总长不在 55–65 秒、五段缺段或顺序错、钩子超过 3 秒、证据和转折段没出处、「最」「第一」「100%」等广告法用词、一条字幕超过 16 字、镜头内容压到字幕区。提醒：数字没写读法、行动段超过 2 句。**有 ✗ 就改稿子或版块，再跑。**

### 7 · 渲染

```
python talkvideo.py render 口播.json
```

出：`产出/名称.mp4`（1080×1920、30fps、人声 −16 LUFS、BGM 自动变速到片长并压到 −29 LUFS）、`名称_封面.png`、`名称_字幕.srt`、`名称_剪映/`（剪辑表 + 每个镜头一张图 + 人声 + BGM）。

要剪映草稿：`python .agents/skills/jianying-draft/scripts/make_draft.py 产出/名称_剪映/剪辑表.json`

### 8 · 发布文案

按 `作业三-口播视频/发布文案模板.md`：3 个标题（20 字内）、封面大字（8 字内，和前 3 秒一致）、正文 100 字内、5 个话题标签，附发布前检查。

## 口播.json 怎么写

文件路径都相对 `口播.json`。完整例子：`作业包/案例/作业三_口播_瀚泱/口播.json`；空白模板：本文件夹的 `模板_口播.json`。

```json
{
 "name": "20261029_口播_v1",
 "brand": {"bg": "#ECEAE4", "ink": "#111214", "accent": "#2E5BFF", "logo": "素材/logo.svg", "right": "右上角一行字"},
 "voice": {"name": "zh-CN-YunyangNeural", "rate": "+8%"},
 "bgm": {"src": "素材/宣传片.m4a", "fit": "stretch", "lufs": -29},
 "cover": "s1@0.5",
 "sentences": [
  {"id": "s1", "seg": "钩子", "scene": "hook", "text": "一台帐篷空调，[15 天]内出货。", "say": "一台帐篷空调，十五天内出货。", "src": "官网 Company"}
 ],
 "scenes": {
  "hook": {"blocks": [{"type": "hero", "value": "15", "unit": "天内出货", "sub": "一台帐篷空调", "image": "素材/产品.png"}]}
 }
}
```

- `seg`：钩子 / 冲突 / 证据 / 转折 / 行动；`scene`：用哪个镜头，相邻的几句可以共用一个镜头
- 版块从上往下自动排，不用写坐标；镜头级可设 `top`（起始高度，默认 220）、`gap`（间距）
- 每个版块（和列表里的每一项）都可以写 `at` 决定什么时候出现：`"s3"` 第 3 句开始、`"s3.1"` 第 3 句的第 2 条字幕、`"+0.3"` 镜头开始后 0.3 秒；`anim`：`up`（默认）/ `left` / `right` / `fade` / `pop`

| 版块 `type` | 用来 | 主要字段 |
|---|---|---|
| `hero` | 钩子：超大数字 + 一行字 + 产品图 | `value` `unit` `sub` `image` |
| `title` | 大字（`\n` 换行，`[ ]` 标主色） | `text` `size` `accent` |
| `kicker` / `note` | 灰色小标题 / 脚注 | `text` |
| `photo` | 照片，慢推；多张按 `at` 切换 | `src` 或 `srcs` `h` `full` `chip` `kb` |
| `cutout` | 透明底产品图 | `src` `h` |
| `rows` | 编号三条（`numbered`）或数据行（`big` + `text`） | `items` `numbered` |
| `bullets` | 小方块要点 | `items` |
| `grid` | 2×2 产品卡 | `items[{src,name,spec}]` |
| `cards` | 一排打勾卡片 | `items` |
| `bars` | 横条对比（第一条高亮） | `items[{label,value,text}]` |
| `number` | 一行「约 3 天」「100 台起」 | `pre` `value` `unit` `size` |
| `banner` | 主色横条 | `text` |
| `logo` / `url` / `images` | 片尾：Logo、网址、一排产品 | `src` `w` / `text` / `srcs` |
| `line` / `spacer` | 分隔线 / 空白 | `h` |

## 规则

- **前 3 秒不放 Logo**：顶栏 Logo 等钩子读完才出现（脚本自动）
- 画面里**不加「AI 生成」角标或水印**；平台发布页按规定勾选「AI 生成」声明即可
- 数字和事实只来自底稿；底稿没有的不说。说型号数量要准（「官网主推 4 款」≠「4 个型号」）
- 字幕在 y≈1420，下方 300 像素留给平台的标题和按钮；屏幕大字只放数字和关键词，不抄整句
- 用别人的脸和声音必须有书面授权；客户 Logo、人脸未同意的不出镜
- 已有产出不覆盖：改版就把 `name` 升到 `_v2`

## 常见坑（第一版最容易不过的）

| 现象 | 改法 |
|---|---|
| 读出来不到 55 秒 | 加一句硬信息（交期、保修、起订量），不要放慢语速凑 |
| 结尾两个行动（「上官网」+「来看厂」） | 第二个挪到转折段，去回应冲突里的某个痛点 |
| 「最大」「最快」 | 改成区间或具体数字：「3000 到 6000BTU」 |
| 合成配音把型号、网址读成一串字母 | 写 `say`；网址不读，只上屏 |
| 字幕一条太长 | 稿子里加逗号；脚本会在「、」处再切 |

## 输出

- `产出/日期_事实底稿.md`、`产出/日期_口播稿_v1.md`（五段表 + 每句出处 + 自查记录）
- `口播.json`：改稿子、改画面都改这一份，重跑就是新版本
- `产出/名称.mp4`、`名称_封面.png`、`名称_字幕.srt`、`名称_镜头总览.jpg`、`名称_剪映/`
- `产出/日期_发布文案_v1.md`
