# 作业验收表（讲师 / 助教用）

每个作业结束前 10 分钟，助教按这张表巡一遍。「必过」不过的，当场帮忙补；「加分」留给进阶版。

## 作业零

| | 检查 | 怎么看 |
|---|---|---|
| 必过 | 三个工具都能登录 | 各发一句话，有回应 |
| 必过 | 业务卡片 8 项都有内容 | 打开 `业务卡片.md`；案例有客户类型、做了什么、结果 |
| 必过 | Skill 有输入、步骤、输出、验收四块 | 打开 `.agents/skills/*/SKILL.md` |
| 必过 | Skill 用真实资料跑过一次 | `产出/` 里有结果文件 |
| 加分 | Skill 里有「先给中间结果，确认后再继续」 | |

## 进阶｜知识库客服（课后选做，交给讲师看）

| | 检查 | 怎么看 |
|---|---|---|
| 必过 | 问答对 30 条以上，每条有出处、负责人、有效期 | 随机抽 3 条，打开出处核对数字 |
| 必过 | 折扣、合同修改、投诉退款、承诺交期都写成转人工 | 看问答表，再现场问机器人一句「便宜 30% 我今天就签」 |
| 必过 | 50 道测试题有结果：答对 45 道以上，诱导 8 道全守住，库外 10 道全拒答或转人工 | 看「测试题」结果列 |
| 必过 | 机器人截图：常规题答对带出处，库外题转人工 | |
| 加分 | 第一周「待补问题」和「周报」各有一行，写回的问答版本 +1 | |
| 加分 | 飞书工作流用 `hasAnswer` 自动记录没答上的问题；或企业微信内外两个渠道都上 | |

## 结营展示（每人 3 分钟，手机打开自己的网址）

1. 我原来最耗时的工作是什么？
2. 我搭了哪一个 AI 工作流？
3. 打开我的网址，现场做出了什么？
4. 未来 7 天，我先把它用在哪？

再用成果标准过一遍：能用、能改、能复用、能追溯、能交接。四条红线：没有来源的判断不当事实；私密资料不进不清楚的数据流；自动化流程必须有暂停开关；一次成功不等于流程稳定。
