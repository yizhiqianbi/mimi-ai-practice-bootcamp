## 照着做：6 句话

**1 · 事实底稿**
> 读 www.你的官网.com（或 业务卡片.md + 知识库/），摘一份口播用的事实底稿：每条写原文和出处；没写的标「未写」，不要补编。

检查：每个数字能点回原文；客户案例、价格、认证没有就写「未写」。

**2 · 钩子**
> 讲给「____」听，行动是「____」。给 3 个钩子：反常识、具体数字、点名处境，每个 20 字以内，写出处。

检查：数字钩子的数字在底稿里；选一个能静音看懂的。

**3 · 口播稿**
> 用 talk-video 写五段口播稿，钩子用「____」，行动指向 ____。每句写出处和读法，写进 口播.json。

检查：只有一个行动；没有「最」「第一」；证据段没案例就标「待提供」。

**4 · 配音 + 自查**
> 用 talk-video 配音，然后跑 check，没过就按提示改稿子，改到通过。

检查：55–65 秒；钩子 3 秒内读完；戴耳机听一遍型号和数字。

**5 · 分镜**
> 用 talk-video 按 素材/ 排 11 个左右镜头，出镜头总览给我看。

检查：一个镜头只说一件事；内容不压字幕；前 3 秒没有 Logo。

**6 · 成片 + 发布**
> 用 talk-video 渲染成片，生成剪映草稿，再按发布文案模板写标题、封面字、正文和标签。

检查：静音看前 3 秒能停下；发布页勾选「AI 生成」声明。

## 换成你的业务

| 瀚泱用的 | 你换成 |
|---|---|
| 官网 + `llms.txt` | 业务卡片、知识库或你的官网 |
| 「15 天内出货」 | 你最硬的一个数字：交期、价格、案例结果 |
| 产能、型号代替客户案例 | 有真实案例就用案例 |
| 官网产品抠图、工厂照片 | 你的产品图、现场照片、截图 |
| 宣传片原声当配乐 | 你自己有授权的音乐 |
| 合成配音 | 每句录一条放进 `录音/`，脚本会优先用 |

## 红线

- 事实只用底稿里的；别人的脸、声音、Logo 没授权不用
- 画面里不加「AI 生成」角标；发布时在平台发布页勾选声明
