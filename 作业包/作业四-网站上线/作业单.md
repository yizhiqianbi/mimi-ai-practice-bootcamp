## 步骤

### A · 写清三件事（10 分钟）

填 `网站三件事.md`：**用户是谁、来做什么、我们收集什么**。这是给 Codex 的需求，越具体生成越准。

### B · 首页 + 表单（40 分钟 · Codex + Grokbot）

1. 想省时间：把 `网站模板/` 复制到 `site/`，**只替换内容**
2. 用下面的示例指令（智能程度调到 **High**）
3. 让「业务顾问」把 FAQ 问题改成**客户真会问的说法**，答案不改事实
4. 表单：基础版用第三方表单（讲师现场指定），嵌入代码贴进模板的表单位置

✓ 检查：FAQ **第一句就是结论**，AI 可以直接引用

### C · 本地自查（25 分钟 · Codex）

1. 浏览器打开 `site/index.html`；看手机效果：`F12` → 左上角手机图标
2. 改两轮：先看**首屏 3 秒**，再看**手机错位**
3. 说：「用 seo-check 这个 Skill 检查 site/」，对照 `SEO8项自查表.md` 打勾
4. 填 `事实底稿模板.md`，存为 `知识库/事实底稿.md`

### D · 部署 + 接通知（30 分钟 · Codex + WorkBuddy）

1. 按 `网站模板/README.md` 部署。Codex 联网会弹请求，**看清再批准**
2. 拿到网址后，让 Codex 把 `site/` 里所有 `https://example.com` 换成正式网址，**再部署一次**
3. 打开表单服务自带的邮件或企业微信通知；或让 WorkBuddy 读通知邮件推到企业微信
4. **手机提交一条测试线索**，确认收到

### E · 每周复测（15 分钟 · Grokbot + Codex）

1. 按 `GEO测试问题表.xlsx` 写 20 个问题
2. Grokbot 新建「竞品观察员」Bot（按 `竞品观察员Bot.md`），建**每周一 09:00** 例行任务
3. Codex 设**每周五 17:00** 更新知识库索引

到这里**三个定时任务齐了**：邮件日报、GEO 复测、知识库索引。

### F · 铺信源（课后选做，第一个月）

网站只是 AI 认识你的一处。打开 `平台信源清单.xlsx`：

1. **账号一致性**：第 2 行抄事实底稿，已有账号逐个对，名称、简介、电话地址不一致的先改
2. 做 1688 或阿里巴巴国际站的，按「B2B店铺8项」自查
3. 链接收齐后说：「把这些链接写进 site/ 的 Organization 结构化数据 sameAs，再部署一次」
4. **分发计划**排四周：FAQ、视频、案例按平台改写，改写交给 Codex

## 示例指令（B 步）

```markdown
角色：你是我的网站开发助理
目标：交付一个单页网站 site/index.html，手机和电脑都能正常看，能部署到静态托管
输入：网站三件事.md；业务卡片.md；知识库/FAQ素材.md；assets/brand.md 和 assets/ 里的图片；产出/____.mp4
约束：
- 文字全部来自上面的文件，不编数字、资质、客户名；缺的写「待确认」并列给我
- 首屏：一句话结论 + 主视觉 + 一个按钮跳到表单
- FAQ 用 FAQ素材.md 原文，同时写一份内容完全一致的 FAQPage JSON-LD
- 表单只收「网站三件事.md」里写的字段
- 有 site/ 里的模板就在模板上改，不要从头写
验收：手机宽度 375px 下没有横向滚动条；首屏 3 秒能看懂卖什么；表单字段和三件事一致；FAQPage 和页面文字一致
节奏：先给我页面结构（每个区块放什么），我确认后再写代码
```
