# 作业四｜把你的业务网站上线

约 120 分钟（Day 2 13:30–15:30）｜课件第 49 页｜讲师样例见课件第 44–48 页；平台和社媒见第 50–52 页（作业四之后讲）

图文教程（每一步的截图、可复制的指令和参考结果）：`作业包/教程/作业四教程.html`

## 目标

1. 一个手机能打开的公开网址：首屏用作业二的主视觉，中间是作业三的视频，FAQ 来自作业一，最后是表单
2. 表单能收线索，提交后你能收到通知
3. 一份 SEO / GEO 清单：SEO 8 项全部通过，20 个 GEO 测试问题交给 Grokbot 每周复测

## 开始前确认手里有这些

| 来自 | 文件 | 用在 |
|---|---|---|
| 作业零 | `业务卡片.md` | 首屏文案、卖点 |
| 作业一 | `知识库/FAQ素材.md` | FAQ 区块 + FAQPage 结构化数据 |

缺哪个先用占位，不要停下来补。

## 步骤

### A · 写清三件事（10 分钟）

填 `网站三件事.md`：用户是谁、来网站做什么、我们要收集什么信息。这页是给 Codex 的需求，写得越具体，它生成得越准。

### B · 生成首页和表单（40 分钟）· Codex + Grokbot

1. 卡住了或想省时间：把 `网站模板/` 整个复制到业务文件夹的 `site/`，只替换内容
2. 在 Codex 里用下面的示例指令（智能程度调到 High）
3. 让 Grokbot「业务顾问」把 FAQ 的问题改成客户真会问的说法，答案不改事实
4. 表单：基础版用第三方表单（讲师现场告诉你用哪个），把它给的嵌入代码贴进模板的表单位置

✓ 检查：FAQ 写的是事实，第一句就是结论，AI 可以直接引用

### C · 本地预览，按清单自查（25 分钟）· Codex

1. 浏览器打开 `site/index.html`；手机看：Chrome 按 `F12` → 左上角手机图标
2. 改两轮：第一轮看首屏 3 秒能不能看懂，第二轮看手机上有没有错位
3. 在 Codex 里说：「用 seo-check 这个 Skill 检查 site/」，对照 `SEO8项自查表.md` 打勾
4. 填 `事实底稿模板.md`，存为 `知识库/事实底稿.md`。网站上的公司名、地址、电话都以它为准

### D · 部署上线，接通知（30 分钟）· Codex + WorkBuddy

1. 按 `网站模板/README.md` 的步骤部署。Codex 要联网时会弹出请求，看清楚再批准
2. 拿到网址后，让 Codex 把 `site/` 里所有的 `https://example.com` 换成正式网址，再部署一次
3. 线索通知：表单服务自带的邮件或企业微信通知打开；或者让 WorkBuddy 读表单通知邮件，推到企业微信
4. 用手机打开网址，提交一条测试线索，看自己能不能收到

### E · 交给 Grokbot 每周复测（15 分钟）

1. 按 `GEO测试问题表.xlsx` 写 20 个问题
2. 在 Grokbot 新建「竞品观察员」Bot，按 `竞品观察员Bot.md` 设置，建每周一 09:00 的例行任务
3. 在 Codex 里设每周五 17:00 更新知识库索引

到这里，三个定时任务就都配齐了。

### F · 铺信源（课后选做，第一个月）

网站只是 AI 认识你的一处。打开 `平台信源清单.xlsx`：

1. 「账号一致性」：第 2 行抄事实底稿，已有的平台账号逐个对，名称、简介、电话地址不一致的先改
2. 做 1688 或阿里巴巴国际站的，按「B2B店铺8项」自查
3. 账号链接收齐后，在 Codex 里说：「把这些链接写进 site/ 的 Organization 结构化数据 sameAs，再部署一次」
4. 「分发计划」排好四周的发布：作业一的 FAQ、作业三的视频、业务卡片里的案例按平台改写，改写交给 Codex

## 示例指令（B 步）

```markdown
角色：你是我的网站开发助理
目标：交付一个单页网站 site/index.html，手机和电脑都能正常看，能部署到静态托管
输入：网站三件事.md；业务卡片.md；知识库/FAQ素材.md；assets/brand.md 和 assets/ 里的图片；产出/____.mp4
约束：
- 文字全部来自上面的文件，不编数字、资质、客户名；缺的写「待确认」并列给我
- 首屏：一句话结论 + 主视觉 + 一个按钮跳到表单
- FAQ 用 FAQ素材.md 原文，同时写一份内容完全一致的 FAQPage JSON-LD
- 表单只收「网站三件事.md」里写的字段
- 有 site/ 里的模板就在模板上改，不要从头写
验收：手机宽度 375px 下没有横向滚动条；首屏 3 秒能看懂卖什么；表单字段和三件事一致；FAQPage 和页面文字一致
节奏：先给我页面结构（每个区块放什么），我确认后再写代码
```
