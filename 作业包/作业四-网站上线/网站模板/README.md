# 网站模板

一个单页静态网站，替换内容就能上线。SEO 8 项里能在代码里做的，模板都预留好了。

## 文件

| 文件 | 作用 | 要改什么 |
|---|---|---|
| `index.html` | 网站本身 | 所有写着「改成」的地方；`:root` 里的品牌色；`https://example.com` 换成正式网址 |
| `robots.txt` | 告诉搜索引擎和 AI 爬虫可以抓取 | 只改网址 |
| `sitemap.xml` | 网址清单，提交给百度、Google、Bing | 改网址和日期 |
| `llms.txt` | 给 AI 的一页说明 | 照事实底稿写 |
| `assets/` | 图片和视频（自己建） | 放 `hero.jpg`、`video.mp4`、`video-cover.jpg`、`logo.png`、`cover.jpg` |

## 让 Codex 替换内容

```markdown
把 site/ 里所有「改成」开头的占位，按 网站三件事.md、业务卡片.md、知识库/FAQ素材.md、知识库/事实底稿.md、assets/brand.md 替换。
FAQ 区块和 head 里的 FAQPage 要一字不差。找不到内容的占位不要编，列给我。
改完用浏览器打开检查，手机宽度 375px 下不能有横向滚动条。
```

## 图片和视频

- 首屏图：横版，宽 1600px 左右，压缩到 300KB 以内（可以用 squoosh.app）
- 视频：mp4，1080p，60 秒控制在 20MB 以内；太大就上传到视频号或 B 站，用平台的嵌入代码
- 分享卡片图 `cover.jpg`：1200×630

## 部署

> 【讲师课前确认】最终用哪个静态托管平台、哪个表单服务，以现场通知为准。下面是通用步骤。

1. 确认 `site/` 里有 `index.html`，图片路径都是相对路径（`assets/...`）
2. 登录托管平台 → 新建项目 → 选「直接上传」→ 把 `site/` 文件夹拖进去
3. 等 1 分钟，拿到一个公开网址
4. 让 Codex 把所有 `https://example.com` 换成这个网址，再上传一次
5. 用手机流量（不连 Wi-Fi）打开，确认能访问

也可以让 Codex 帮你部署：「把 site/ 部署到 ____，先告诉我要装什么、要登录什么，我确认后再做」。它要联网、要装命令行工具时会弹出请求，看清楚再批准。

## 上线后

- 提交测试线索，确认收得到通知
- 按 `SEO8项自查表.md` 第 7 项提交百度、Google、Bing
- 把网址填回：PPT 最后一页、海报二维码、口播视频的发布文案
