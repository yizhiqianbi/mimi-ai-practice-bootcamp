# 公开资料：GB/T 39600-2021 人造板甲醛释放量分级

- 查询日期：2026-10-28
- 查询方式：Grokbot「业务顾问」
- 来源网址（打开核对过）：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F5BCAEB886FB1417F12395B61AFDB178 （国家标准全文公开系统）

## 要点

- 标准名称：GB/T 39600-2021《人造板及其制品甲醛释放量分级》，现行，2021-10-01 实施
- 发布单位：国家市场监督管理总局、国家标准化管理委员会
- 三个等级：

| 等级 | 甲醛释放限量 |
|---|---|
| E1 | ≤ 0.124 mg/m³ |
| E0 | ≤ 0.050 mg/m³ |
| ENF | ≤ 0.025 mg/m³ |

## 用在哪

- 客户问「ENF 是什么」「甲醛怎么样」时，可以说清楚 ENF 是国标里限量最严的一级
- 和 `02_产品与价格/产品与价格_板材环保等级说明_2026.pdf` 的数值一致
