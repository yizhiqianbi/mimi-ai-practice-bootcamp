# 找名单（带证据和来源）

## 一句话调用

> 用 lead-hunt：我在柏林有约 85 m³ 移动空调库存，换季卖不动。找柏林及周边有仓库、能帮存货再分润代销的商家。只用公开资料，每家写清仓储证据和来源，分 A/B/C 档，出 Excel。先别联系。

## 需要

- 能上网搜索、打开网页的智能体（Codex、WorkBuddy、Grokbot 都行）

## 输入

- 货：____（例：移动单体空调 Monoblock）
- 量和地点：____（例：约 85 m³，柏林）
- 要找谁：____（例：有仓库、卖空调的批发、电商、租赁公司）
- 硬条件：____（例：必须有仓库证据）
- 想怎么合作：____（例：帮存货 + 寄售代销，分润）
- 不要：____（例：只收尾货压价的）

## 步骤

1. **拆任务卡**：把上面几项写成一张任务卡，再列出准备用的搜索词（当地语言 + 英文），例：`mobile Klimageräte Berlin Großhandel`、`Klimagerät Verleih Berlin`。**给我看任务卡和搜索词，等我确认。**
2. **搜**：按渠道类型分开搜：批发、电商、租赁、暖通贸易、仓配和代发。先列 30–50 家候选
3. **逐家核实**：打开每家的官网或公开企业页，找三样东西：
   - 卖不卖这类货（品类页、产品页）
   - 硬条件的证据（例：「ab Lager Berlin」「从柏林仓库发货」「11,000 ㎡ 室内仓」），**原话摘下来**
   - 公开的邮箱、电话、地址
   找不到证据的写「未公开」，不要猜。已停业、只做安装不卖货的直接剔除，写进落选表
4. **打分分档**：
   - A：品类对口 + 在目标城市 + 有硬条件证据，首批联系
   - B：品类对口，但仓不在目标城市，或是全国大批发
   - C：品类或仓容还没核实，只谈小批量或租赁
   每家写一句为什么是这个档
5. **写说明页**：分档规则、建议首批联系哪几家、首次沟通要问清的问题、要提前准备的资料包（型号、数量、托盘数、证书等）
6. 在对话里只回：几家、各档几家、首批建议、最没把握的 3 家

## 规则

- **只查不联系**：不发邮件、不填表单、不打电话
- 每一条证据都要有来源链接，链接打不开的不算
- 「有仓库」不等于「愿意接你的货」：说明页里写清楚，留给开发信去问
- 只用公开页面；不登录、不绕验证码、不批量抓取

## 输出

- `产出/日期_名单_v1.xlsx`
  - 「名单」页：序号、公司、档、渠道类型、匹配度、证据（原话）、城市、地址、电话、邮箱、官网、匹配理由、建议下一步、来源
  - 「落选」页：公司、落选原因
  - 「说明」页：分档规则、首批建议、首次沟通要点、资料包清单

## 验收

- [ ] 随便点开 3 家的来源，证据原话能在页面上找到
- [ ] A 档每家都有硬条件证据，不是「可能有」
- [ ] 候选总数 = 入选 + 落选
- [ ] 没有任何一家被联系过
