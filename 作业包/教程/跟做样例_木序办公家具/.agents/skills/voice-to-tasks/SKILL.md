# 语音派活（WorkBuddy + 企业微信）

## 一句话调用

> （在企业微信里发语音给 WorkBuddy）用 voice-to-tasks 把这段话拆成待办

## 需要

- WorkBuddy 连好企业微信，能读你发的语音、能往指定群发消息
- `资料/团队.md`：每个人的名字、负责什么、在哪个群
- 定时任务：每天 17:30 追进度，每周五 17:30 汇总

## 输入

- 一段语音或一段文字（例：「小李这周把王经理那单的送货时间定下来，周四前给我；娜娜把 7 月那几笔尾款催一下……」）

## 步骤

1. **转文字**，原话存进 `待办/原话/日期.md`
2. **拆待办**：每条写：做什么、负责人（按团队表对上）、截止时间、怎么算做完。听不清或没说的写「待确认」
3. **给我确认**：在企业微信回我一张待办清单。**等我回「发」才往下做**，我改哪条就改哪条
4. **发群**：按负责人发到对应的群，@ 到人，一人一条
5. **记账**：写进 `待办/待办总表.xlsx`：日期、事、负责人、截止、状态
6. **追进度**：每天 17:30 问一遍当天到期的；周五汇总：做完几条、延期几条、卡在哪

## 规则

- 不经我确认不发群
- 人名对不上团队表的，问我，不猜
- 涉及钱、人事、客户承诺的待办，只发给负责人，不发大群
- 原话只存本机

## 输出

- 群里一人一条带 @ 的待办
- `待办/待办总表.xlsx`
- 每周五的汇总消息

## 验收

- [ ] 每条待办都有负责人和截止时间，或者标了「待确认」
- [ ] 发出去的和我确认的一致
- [ ] 周五汇总的数字和总表对得上
