# 改成你的 Skill 名字

## 输入

- 资料：`资料/____`（文件类型：____）
- 参考：`业务卡片.md`

## 步骤

1. 读完输入资料，列出要处理的内容清单，先给我看
2. 我确认后，按下面的「输出」格式逐项处理
3. 遇到看不清、对不上、缺数字的地方，写「待确认」并说明原因，不要猜
4. 按「验收」逐条自查，把自查结果写在最后

## 输出

- 文件：`产出/日期_____.md`
- 格式：

```markdown
# 标题
## 一句话结论
## 正文
## 待确认
```

## 验收

- [ ] ____（例：每条待办都有负责人和截止日期）
- [ ] ____（例：数字都能在原文找到）
- [ ] ____（例：一页以内）
