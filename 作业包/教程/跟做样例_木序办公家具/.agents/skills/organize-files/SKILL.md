# 整理资料，生成知识库和总索引

## 输入

- `资料/`（只读，不改不删）
- `业务卡片.md`

## 步骤

1. **盘点**：列出 `资料/` 下全部文件（含子文件夹），每个文件打开看内容，写一句话摘要。打不开的单独列出。先把盘点表给我看。
2. **找问题**，分三类列给我：
   - 重复：内容相同或几乎相同的文件
   - 过期：同一主题有新旧版本，写清楚哪个新、依据是什么（日期、版本号、内容）
   - 冲突：同一个事实在两个文件里说法不一样（价格、质保年限、交期等），写出两边原文和出处
3. **等我确认**哪些保留、哪些作废，冲突以哪份为准。
4. **归类和改名**：把保留的文件复制到 `知识库/` 下的类别文件夹，文件名改成 `类别_主题_日期或版本`。默认类别：
   - `01_公司介绍` `02_产品与价格` `03_合同与售后` `04_案例` `05_FAQ与话术` `06_流程与制度` `99_其他`
5. **生成 `知识库/总索引.md`**，格式见下。

## 输出：总索引.md

```markdown
# 总索引（更新于 YYYY-MM-DD）

## 01_公司介绍
| 文件 | 一句话内容 | 原文件名 | 状态 |
|---|---|---|---|

## 待确认
- 冲突：____（文件 A 写 __，文件 B 写 __）
- 作废：____（原因）
```

## 验收

- [ ] `资料/` 里每个文件都出现在索引里（保留、作废或打不开），一个不漏；最后写出总数核对：资料 N 个 = 保留 a + 作废 b + 打不开 c
- [ ] 每个冲突都写出两边原文和文件名
- [ ] `资料/` 原件没有被改动
- [ ] 摘要里的数字和原文一致
