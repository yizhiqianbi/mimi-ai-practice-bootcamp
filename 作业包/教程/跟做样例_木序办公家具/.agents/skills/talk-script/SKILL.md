# 60 秒口播稿 + 字幕 + 发布文案

## 输入

- `业务卡片.md`（客户最头疼的问题 → 冲突；真实案例 → 证据；希望客户做什么 → 行动）
- `知识库/`
- 选定的开头钩子：____（作业三 A 步从 Grokbot 给的 3 个里选）
- 行动指向：____（作业四网站网址或表单，网址还没有就先写「官网」占位）

## 步骤

1. 按五段结构写稿，总字数 240–280 字（正常语速约每秒 4–4.5 个字）：

| 段 | 时长 | 写什么 |
|---|---|---|
| 钩子 | 0–3 秒 | 一句话让人停下：反常识、具体数字、直接点名客户的处境 |
| 冲突 | 3–15 秒 | 客户现在怎么做、哪里痛 |
| 证据 | 15–40 秒 | 一个真实案例，带数字 |
| 转折 | 40–52 秒 | 所以应该怎么做，你的方法 |
| 行动 | 52–60 秒 | 只给一个动作：去网站、留电话、私信关键词 |

2. 先给我稿子，标出每段起止秒数和字数。**等我确认。**
3. 生成 SRT 字幕：每条不超过 16 个字，按语气断句，不要把一个词拆成两行。
4. 写发布文案：3 个标题备选（20 字以内）、封面大字（8 字以内）、正文 100 字以内、5 个话题标签。

## 输出

- `产出/日期_口播稿_v1.md`
- `产出/日期_字幕_v1.srt`
- `产出/日期_发布文案_v1.md`

## 验收

- [ ] 读出来计时在 55–65 秒
- [ ] 证据段的数字能在知识库找到出处
- [ ] 结尾只有一个行动
- [ ] 不出现「最」「第一」「100%」等广告法禁用说法，除非有证明材料
