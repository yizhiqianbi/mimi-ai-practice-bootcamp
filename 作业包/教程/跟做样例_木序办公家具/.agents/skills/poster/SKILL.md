# 业务海报

## 输入

- `业务卡片.md`、作业二定下的一句话结论
- `assets/` 里的 Logo、产品图或门店照片
- 模板：`作业包/作业二-PPT与海报/海报模板.html`

## 步骤

1. **先排信息层级**，给我看，不出图：
   - 第一眼（3 秒）：主标题，10 字以内，说清楚是什么
   - 第二眼：给谁、解决什么，1–2 行
   - 第三眼：3 个卖点或活动信息（时间、地点、价格）
   - 最后：怎么联系（二维码位置、电话、网址）
2. 我确认后再定视觉：给 2 个配色方向，每个写出主色、辅色、背景色色值和理由。
3. 填进模板，导出 `产出/日期_海报_v1.html`，用浏览器截图成 PNG。
4. 把选定的颜色、字体、主视觉文件名写进 `assets/brand.md`。

## 验收

- [ ] 离屏幕 2 米看，3 秒内能说出这是什么、给谁、怎么联系
- [ ] 全图文字不超过 80 字
- [ ] 没有用到没有授权的图片、字体（商用字体优先用思源黑体、思源宋体、阿里巴巴普惠体等免费商用字体）
- [ ] `assets/brand.md` 已填写
