# 15 秒广告片（WorkBuddy + LibTV）

## 一句话调用

> 用 libtv-ad 给 ____（产品）做 15 秒广告片，先出 3 个方向

## 需要

- LibTV 账号和 Access Key（liblib.tv，按积分计费）
- 装好 LibTV 官方 Skill `libtv-skills`：
  - WorkBuddy：从 GitHub `libtv-labs/libtv-skills` 下载压缩包 →「专家·技能·连接器」→ 技能 → 上传技能
  - Codex：`npx skills add libtv-labs/libtv-skills`
- 环境变量 `LIBTV_ACCESS_KEY`。Key 不写进任何文件，不发群

## 输入

- `业务卡片.md`：卖什么、给谁、凭什么
- 产品图：`素材/产品/` 里 1–3 张清楚的图（白底最好）
- 用在哪：____（抖音 / 视频号 / 小红书 / 展会大屏），决定画幅
- 这次预算：____ 积分（默认先只做 1 个方向的样片）

## 步骤

1. **写 3 个方向**：痛点型、对比型、案例型各一个。每个方向 5 个镜头 × 3 秒，写清画面、运镜、字幕、声音，最后一个镜头是产品 + 一句行动。**给我看三个方向，等我挑一个。**
2. **上传产品图**：用 `upload_file.py` 传到 LibTV，拿到图片地址，作为每个镜头的参考图
3. **发给 LibTV**：用 `create_session.py` 把选中方向的分镜整段发过去（每个镜头的画面描述 + 参考图 + 画幅），记下 sessionId 和项目画布链接
4. **等结果**：每 30 秒用 `query_session.py --after-seq` 拉一次新消息，直到镜头都生成完
5. **下载**：`download_results.py` 下到 `产出/广告片/日期_方向名/`，按镜头编号命名
6. **检查**：逐个镜头对照产品图看外观（结构、颜色、Logo）。不一致的镜头单独重生，最多 2 次，还不行就标出来让我决定
7. **推送**：WorkBuddy 把成片（或 5 个镜头）和画布链接推到企业微信，附一句：用了多少积分、哪几个镜头重生过
8. 要加字幕、配音、拼成片，接着用 `jianying-draft`

## 规则

- 先做 1 个方向的样片，我点头再做其他方向，避免积分烧完
- 产品外观以上传的图为准，不让 AI 改结构、改 Logo、加不存在的功能
- 不用真人明星、不用别人的品牌和音乐；出现人物的镜头用 AI 生成的路人形象
- 广告词不用「最」「第一」「国家级」这类绝对化用语
- 平台要求标注 AI 生成内容的，发布时勾选

## 输出

- `产出/日期_广告片分镜_v1.md`：3 个方向，选中的那个标出来
- `产出/广告片/日期_方向名/`：镜头 mp4、成片 mp4
- LibTV 项目画布链接（在画布里还能手动改）

## 验收

- [ ] 每个镜头里的产品和产品图对得上
- [ ] 15 秒内讲完一件事，最后有一个明确的行动
- [ ] 用掉的积分在预算内
- [ ] 广告词里没有绝对化用语
