# 剪映草稿（Codex + 剪映）

## 一句话调用

> 用 jianying-draft 把 产出/口播稿 和 素材/ 剪成剪映草稿

## 需要

- 电脑上装好**剪映专业版**（国内版，Windows 或 Mac）。手机版和 CapCut 国际版不行
- `pip install pyJianYingDraft`（Codex 会帮你装）
- 生成前**完全退出剪映**，包括后台进程

## 输入

- 口播稿：`产出/日期_口播稿_v1.md`（作业三的五段稿）
- 字幕：`产出/日期_字幕_v1.srt`。没有就按口播稿和录音时长切
- 素材：`素材/` 里的图片、视频；口播录音 `素材/口播.m4a`（没有也能先排画面和字幕）；BGM（只用有授权的）
- 画幅：____（默认竖版 1080×1920）

## 步骤

1. **盘点**：列出素材文件夹里每个文件、时长和尺寸，标出哪些能用、哪些画质不够
2. **写剪辑表**：按口播稿逐段排：几秒到几秒、用哪张图或哪段视频、要不要推近、要不要加大字标题。缺画面的段落，用 HTML 按品牌色做竖版文字卡片导出 PNG（字幕位置留空）。写成 `产出/日期_剪辑表_v1.json`。**给我看剪辑表，等我确认。**
3. **自检**：`python .agents/skills/jianying-draft/scripts/make_draft.py 剪辑表.json --check`，镜头首尾相接、没有空档、文件都在
4. **生成草稿**：`python .agents/skills/jianying-draft/scripts/make_draft.py 剪辑表.json`。素材先复制进草稿文件夹，再排轨道：画面、字幕、口播、BGM（默认 −20 dB，循环到结尾，最后 2 秒淡出）
5. 告诉我草稿名、总长、几段画面、几条字幕、还缺什么（例：口播录音）

## 规则

- **不覆盖已有草稿**。重名就升版本号（`_v2`）
- 剪映 11.x 以后不要去改已经打开过的草稿里的 `Timelines/` 文件，一律生成新草稿
- 字幕文字和口播稿逐字一致；数字以口播稿为准
- 客户名称、Logo、人脸没有授权的不出镜；BGM 只用有授权的
- Mac 上剪映不能自动导出，生成后在剪映里点「导出」；Windows 也先手动导出，确认效果后再说批量

## 输出

- 剪映草稿列表里一个新草稿：`日期_口播_v1`
- `产出/日期_剪辑表_v1.json`：改画面、改时长都改这张表，重跑一次就是新版本
- `产出/日期_剪辑画面/`：自己做的文字卡片

## 验收

- [ ] 剪映里打开不报「媒体丢失」
- [ ] 总长和口播稿一致，画面之间没有黑场
- [ ] 字幕和口播对得上，逐字一致
- [ ] 改一处剪辑表重跑，能出 `_v2`，原草稿没被动过
