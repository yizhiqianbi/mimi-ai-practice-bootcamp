# 竞品周报（WorkBuddy 定时 + 浏览器）

## 一句话调用

> 用 competitor-watch 盯 资料/竞品清单.md 里的 5 家，每周一早上发我

## 需要

- WorkBuddy：装浏览器操作类技能（例：Agent Browser），连好企业微信
- 定时任务：每周一 08:30

## 输入

- `资料/竞品清单.md`：每家的名字和要看的地址（官网、店铺、公众号、抖音号）
- 关注什么：____（默认价格、新品、活动、案例、招聘）

## 步骤

1. **建基线**（第一次）：逐个打开每个地址，记下价格、在售产品、活动、最新案例，截图，存 `竞品/基线_日期.md`。**给我看基线，等我确认看的东西对不对。**
2. **每周对比**：定时任务打开同样的地址，和上一次记录逐项比
3. **只报变化**：每条写：哪家、什么变了（之前 → 现在）、网址、截图
4. **给建议**：每条一句「要不要跟、怎么跟」，例：「A 家宽工位降到 780，我们 820；先不降价，报价单里强调 15 天交付」
5. 推到企业微信：没有变化就只发一句「本周无变化」；有变化按影响大小排

## 规则

- 只看公开页面；不登录别人的账号、不绕验证码、不批量抓取
- 每周一次就够，不高频访问
- 每条变化都有网址和截图，没截到的不报
- 价格建议只是建议，调价由我决定

## 输出

- `竞品/日期_竞品周报.md`：变化表 + 建议
- `竞品/截图/日期/`
