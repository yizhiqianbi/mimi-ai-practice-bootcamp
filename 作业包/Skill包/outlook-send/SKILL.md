# Outlook 逐封发信（Computer Use）

## 一句话调用

> 用 outlook-send 按 产出/名单_v1.xlsx 的 A、B 档发 产出/开发信_v1.md，前两封停下来给我看

## 需要

- 支持 Computer Use 的智能体（能看屏幕、动鼠标、打字）
- 电脑上登录好的 Outlook（Mac 或 Windows 都行），签名已设好
- 发信期间电脑开着、不锁屏、不去动鼠标

## 输入

- 名单：`产出/` 里审核过的名单表（要有公司、邮箱、档）
- 信件：审核过的范本，主题和正文分开写好
- 发哪些：____（默认 A、B 档）
- 每批上限：____（默认 20 封）；每封间隔：____（默认 10 秒）

## 步骤

1. **对清单**：列出这批要发的收件人（公司、邮箱、档），去掉没有邮箱、标了退订或拒绝的。**给我看清单，等我确认。**
2. **自测**：新建邮件发给我自己。**等我在手机上看过排版、签名、退订说明再继续。**
3. **逐封发**：每一封都是：新建 → 填收件人 → 填主题 → 贴正文 → 看一眼收件人有没有填对 → 发送
4. **前两封停**：发完第 1、2 封各停一次，截图给我看。我说「继续」才往下
5. **限量间隔**：每封之间等一会儿；到每批上限就停，不一次发完几百封
6. **核对**：全部发完，到「已发送」逐封对：收件人、主题、时间。对不上的标出来，不要自己补发
7. 在对话里只回：发了几封、没发的几封和原因、核对有没有问题

## 规则

- 只发清单里我确认过的人和我审过的信，不改正文
- 弹出任何登录、验证码、安全提示，停下来叫我，不自己点
- 发出错了不要撤回或补发，先停下来告诉我
- 发往德国和欧盟的商业邮件，先确认当地规定（德国对未经同意的推广邮件管得严）；每封留退订方式
- 一键暂停：我说「停」，当前这封发完就停

## 输出

- `产出/日期_发送记录.xlsx`：公司、邮箱、档、主题、发送时间、核对结果、备注
- `产出/日期_发送截图/`：自测、前两封、「已发送」列表

## 验收

- [ ] 发送记录里的封数 = 清单封数 − 跳过的封数
- [ ] 「已发送」里每封的收件人和记录表对得上
- [ ] 没有一封发给清单以外的人
