# 回信分拣与跟进

## 一句话调用

> 用 reply-triage 读这几天关于「Vertriebspartnerschaft」的回信，更新跟进表，起草回信

## 输入

- 回信：邮箱里的回信（智能体能读邮箱就直接读；不能就把回信导出或截图放进 `资料/回信/`）
- `产出/日期_发送记录.xlsx` 和名单表：知道每封回信对应哪家、哪一档
- `知识库/`：产品、型号、证书、物流资料，用来判断我们缺什么

## 步骤

1. **对上号**：每封回信对上名单里的公司和档。自动回复、退信、「不感兴趣」单独归一类
2. **读要点**：每封写三行：
   - 对方的态度，摘一句原话（例：「仓容足够考虑这个规模的合作」）
   - 对方要什么：资料、价格、样品、电话、看货，逐条列
   - 对方提了什么条件
3. **对资料**：把对方要的逐条对照 `知识库/`，标「有，文件在 ____」或「缺」。缺的列成资料包待办
4. **定下一步**：每家一个下一步和日期（寄资料、约电话、约看货、放弃）
5. **起草回信**：用对方回信的语言，回答能答的，资料附上或说明哪天给；价格、独家、账期、合同条款写「【待我确认：____】」。**给我看草稿，等我改。**
6. 在对话里只回：几封回信、几家有意向、资料包缺几样、哪几封草稿等我确认

## 规则

- 不替我答应任何价格、独家、账期、退货条件
- 对方要的所有权证明、证书，只给真实文件；没有就写「缺」
- 退订和拒绝的，在名单里标上，以后不再发
- 回信只起草不发送

## 输出

- `产出/日期_跟进表.xlsx`：公司、档、回信日期、态度原话、对方要的、我们缺的、下一步、日期、负责人
- `产出/日期_回信草稿.md`：一封一段，标好待确认处
- `产出/日期_资料包待办.md`：缺的资料、谁去准备、哪天要

## 验收

- [ ] 每封回信都在跟进表里，自动回复和退信单独列
- [ ] 对方要的每一样，都标了「有」或「缺」
- [ ] 草稿里没有一处我没确认过的价格或条款
