# 业务官网

## 一句话调用

> 用 site-build 按 网站三件事.md 做我的官网，放进 site/

## 输入

- `网站三件事.md`：用户是谁、来做什么、要收集什么
- `业务卡片.md`、`知识库/FAQ素材.md`、`知识库/事实底稿.md`
- 作业二的一句话结论和海报主视觉、作业三的视频（`assets/`）
- 模板：`作业包/作业四-网站上线/网站模板/`（复制到 `site/` 再改）

## 步骤

1. **先给我页面清单**：每个区块写什么、内容来自哪个文件、按钮上写什么。**等我确认。**
2. **填内容**：按下面的区块顺序改模板。文字只用输入文件里的，缺的写「待补：____」，不编。
3. **表单**：只放网站三件事里列的字段，按钮写成具体动作（例：「预约免费量尺」）。提交后显示什么、线索推给谁，按网站三件事写。
4. **手机检查**：用 390 像素宽预览，首屏能看到一句话和按钮，没有横向滚动，图片不超过 300 KB。
5. 列出还要我补的内容和要替换的占位。

## 页面区块（按顺序）

| 区块 | 内容来自 |
|---|---|
| 首屏：一句话 + 主视觉 + 按钮 | 作业二 |
| 3 个卖点 | 业务卡片「凭什么能解决」 |
| 视频 | 作业三 |
| 1 个案例：问题 → 做了什么 → 结果 | 业务卡片「真实案例」 |
| FAQ 5 问 | `FAQ素材.md` |
| 表单 + 联系方式 | 网站三件事 + 事实底稿 |

## 输出

- `site/index.html`（单文件，图片放 `site/assets/`）
- 对话里给一张待补清单

## 验收

- [ ] 手机上首屏能看到一句话和按钮
- [ ] 页面上的数字、地址、电话都能在事实底稿里找到
- [ ] 表单字段和网站三件事一致，按钮不是「提交」「了解更多」
- [ ] 没有横向滚动，没有打不开的图片和链接
- [ ] 下一步：用 seo-check 查 8 项，再部署
