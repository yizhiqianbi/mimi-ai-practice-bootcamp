# 定制开发信

## 一句话调用

> 用 outreach 处理 资料/名单.xlsx，挑前 20 个，写定制开发信

## 输入

- 名单：`资料/` 里的 xlsx 或 csv。表头不统一没关系（FastMoss、Kalodata、展会名录、海关数据导出的都行），先自动认列
- `业务卡片.md`：卖什么、给谁、凭什么、希望对方做什么
- `知识库/`：产品、卖点、案例、样品政策
- 客户画像：____（例：美国、户外和露营品类、粉丝 1 万–50 万、近 30 天有发视频）
- 这批要几个：____（默认 20）

## 步骤

1. **认表头**：列出每一列认成了什么（名称、平台或网站、国家、品类、粉丝或规模、邮箱、主页链接），认不出的列原样保留。**给我看对照表。**
2. **打分**：按画像给每一行打 0–100 分，每个分数写一句理由（例：「品类对口 +30，粉丝 8 万在区间 +20，没有邮箱 −40」）。没有联系方式的排到最后。
3. **挑人**：按分数挑前 N 个，给我看名单和理由。**等我确认或删减。**
4. **找切入点**：每个人只用名单里有的信息和公开主页，找一个能写进信里的具体点（最近一条内容、主营产品、所在市场）。找不到就写「无个性化素材」，不要编。
5. **写信**：每封都用对方的语言，结构固定：
   - 主题：一句话，带对方的名字或品类
   - 第一句：提到那个切入点，证明不是群发
   - 中间：一个和对方相关的产品或卖点，一个真实案例或数字（来自知识库）
   - 结尾：只提一个小请求（例：要不要寄样品、方不方便 15 分钟视频）
   - 落款用业务卡片里的称呼和公司名；最后一行写退订方式
6. 全部写进草稿表，在对话里只回：几封、平均分、哪几封标了「待确认」。

## 规则

- **只起草，不发送**。发信由我审核后，用我自己的邮箱发
- 提到佣金、价格、独家、合同条款的，写「【待我确认：____】」
- 不编对方的数据、不编我们的案例；每封信里的事实都能在名单或知识库找到
- 名单里标了退订或拒绝的，直接跳过

## 输出

- `产出/日期_开发信草稿.xlsx`：名称、平台、国家、分数、理由、切入点、主题、正文、语言、状态（待审核）
- `产出/日期_开发信草稿.md`：同样内容，方便逐封看

## 验收

- [ ] 名单总数 = 入选 + 落选 + 跳过，数得上
- [ ] 每个分数都有理由
- [ ] 随便挑 3 封，第一句都提到对方的具体信息，不是换个名字的模板
- [ ] 每封只有一个请求，最后有退订方式
- [ ] 没有一封被发出
