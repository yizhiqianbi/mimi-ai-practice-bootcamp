# 经营看板（Codex + 表格，可接 WorkBuddy 每周推送）

## 一句话调用

> 用 boss-dashboard 把 资料/销售明细.xlsx 做成经营看板

## 输入

- 数据：`资料/` 里的 xlsx 或 csv（ERP、金蝶、用友、管家婆、自己记的表都行）。订单、明细、回款可以是几张表
- `知识库/` 里的价格表和客户名单（用来算加购空间、对上客户）
- 今年目标：____（没有就不算完成率）

## 步骤

1. **认表头**：每张表每一列认成了什么（日期、客户、金额、已回款、状态、产品、数量、销售），认不出的原样保留。**给我看对照表。**
2. **定口径**：列出要用的口径，例：签约额按签约日期还是交付日期、含不含税、退货怎么算、尾款怎么算逾期。**等我确认。**
3. **算**：
   - 总量：签约额、单数、客单价；按月趋势；和上月、去年同期比（有数据才比）
   - 结构：品类、城市、销售、客户集中度（前 5 名占比）
   - 回款：在途应收和逾期尾款分开，逾期逐笔列出：订单号、客户、销售、金额、逾期天数
   - 机会：只买了一部分品类的订单，按价格表算加购空间
4. **挑三件事**：从上面挑最值得老板这个月管的三件，每件写成一句话结论 + 依据数字 + 一个建议动作（谁、做什么、什么时候）
5. **出看板**：单个 HTML 文件，手机优先，图表用内嵌 SVG，不连外网。顶部四个数，接着三件事，再往下是趋势、逾期表、品类。底部写口径和数据来源
6. 截一张手机截图，在对话里只回三件事

## 规则

- 每个数字都能在源表里按订单号或行号找到；算不出来就写「数据里没有」，不估
- 「如果……就能多……」这类潜力数字写清前提，不写成预测
- 客户名和金额明细只留在本机；发群、发老板只发三件事的文字
- 每周自动跑：在 WorkBuddy 建定时任务（每周一 08:30），读最新导出，生成新一版看板，只把三件事推到企业微信

## 输出

- `产出/日期_经营看板_v1.html`
- `产出/日期_经营结论_v1.md`：三件事 + 口径 + 怎么核对

## 验收

- [ ] 随便挑 3 个数字，能在源表找到并算对
- [ ] 三件事每件都有数字和一个具体动作
- [ ] 手机打开不用左右滑
- [ ] 口径写在看板底部
