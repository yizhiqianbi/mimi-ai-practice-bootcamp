# Skill 包：一句话，一个结果

13 个 Skill，每个解决老板身边一件天天发生的事。装好以后，对 Codex 说一句话，结果直接落在 `产出/`。

## 怎么装

`工作区模板/我的业务/.agents/skills/` 里已经装好了同一套，作业零复制工作区模板时就装上了。

单独装：把这个文件夹里的子文件夹整个复制到你业务文件夹的 `.agents/skills/` 下面（注意 `.agents` 前面有个点），在 Codex 里重新打开项目。

## 怎么用

照「一句话这样说」那一列说就行。Codex 会先给你看中间结果（盘点表、大纲、名单），你点头它才继续。

## 每个 Skill 都一样的四件事

1. **先给中间结果**：盘点表、大纲、名单，你确认了才往下做
2. **不编**：数字和事实只用 `知识库/` 和输入文件里的，缺的写「待确认」
3. **不替你出手**：发信、发帖、付款、删除，一律只起草，等你来
4. **自带验收**：最后按验收清单逐条打勾，不过关就改 Skill 再跑，不是手改结果

## 改成你自己的

1. 挑一个最接近你最耗时那件事的 Skill，复制一份改名
2. 只改「输入」「输出」「验收」三块，步骤先照抄
3. 拿一份真实资料跑一次；结果不对，改 Skill 再跑

从零写就复制 `_skill模板/`。
