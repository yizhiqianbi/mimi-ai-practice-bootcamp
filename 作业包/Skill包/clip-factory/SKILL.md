# 长视频切片（Codex + 剪映）

## 一句话调用

> 用 clip-factory 把 素材/____.mp4 切成 5 条短视频

## 需要

- 剪映专业版 + `pyJianYingDraft`（同 `jianying-draft`）
- 转写：本机 `faster-whisper`（Codex 帮你装），或者先在通义听悟、飞书妙记里转好，导出带时间的 srt

## 输入

- 长视频：`素材/` 里的 mp4 或 mov，最好 2 小时以内
- 这批给谁看：____（例：想换办公室的公司行政）
- 要几条：____（默认 5）

## 步骤

1. **转写**：生成带时间的逐句文字稿 `产出/日期_转写.srt`
2. **挑候选**：从文字稿里挑 10 段 30–60 秒的候选，每段写：起止时间、一句话讲了什么、为什么值得发（一个完整观点 / 有具体数字 / 有冲突或金句）、开头 3 秒是不是抓人。**给我看候选表，等我挑 5 段。**
3. **修边**：每段的开头掐掉「嗯」「那个」，从有信息的第一句开始；结尾停在一句话说完的地方
4. **出草稿**：每段写一张剪辑表，用 `jianying-draft` 的 `make_draft.py` 生成竖版 1080×1920 草稿：视频镜头用 `source_start` 指向原视频起点，字幕按起点平移成从 0 开始，顶部一行标题（≤ 14 字）。草稿名 `日期_切片_01` … `_05`
5. **写文案**：每条一段发布文案 + 3 个话题标签，写进切片表

## 规则

- 只切这段视频里真说过的话，标题不夸大、不改原意
- 出镜的人没同意公开的，不切；客户名称和价格出现的段落先问我
- 不覆盖已有草稿

## 输出

- 剪映里 5 个新草稿
- `产出/日期_切片表.md`：每条的起止时间、标题、文案、标签

## 验收

- [ ] 每条单独看能看懂，不需要前情
- [ ] 开头 3 秒就有信息
- [ ] 字幕和原话一致
