# 作业一｜业务知识库 + 邮件助理

**105 分钟**（含 15 分钟茶歇，Day 1 14:25–16:25）｜课件第 29 页｜之后 16:25–17:00 小组互查

图文教程：`作业包/教程/作业一教程.html`（每步截图、可复制指令、参考结果）

## 交付物与验收

| 交付物 | 验收标准 | 后面用在 |
|---|---|---|
| `知识库/` + **`总索引.md`** | **总数对得上**：资料 N 个 = 保留 + 作废 + 打不开；找出**至少 3 处冲突或过期** | 所有作业的事实来源 |
| **3 个问答**（截图或文字） | 每个答案**带出处**（文件名 + 位置），和原文一致 | — |
| **邮件日报**截图 + 定时任务 | 13 封全在；订单号、日期、人数**没写错**；可疑邮件单独标出；**只起草不发送**（「已发送」是空的） | 每天 08:30 自动推送 |
| **`知识库/FAQ素材.md`** | 5 个问题用**客户原话**；每个答案有出处 | 作业四网站 FAQ |

## 资料

- 带了自己资料：复制到 `资料/`
- 没带：复制 `示例资料_木序办公家具_虚构/` 的 30 个文件到 `资料/`，邮件用 `示例邮件/`

示例资料故意做得像真实公司一样乱：**重复、新旧版本、说法冲突、私人文件**都有。你的任务是让 AI 把它们**挑出来**，不是全收进知识库。

## 步骤

### A · 整理资料 → `总索引.md`（30 分钟 · Codex）

1. 说：「用 organize-files 这个 Skill 整理 资料/」
2. 它先给**盘点表和问题清单**（重复、过期、冲突），**以哪份为准由你定**
3. 确认后它归类、改名、复制到 `知识库/`，生成 `总索引.md`

✓ 检查：总数核对对得上；抽 3 条摘要，打开原文对数字

### B · 带出处的问答 → 3 个问答（20 分钟 · Codex + Grokbot）

1. 写 3 个客户**真问过**的问题，用下面的示例指令问 Codex
2. 打开出处文件，**核对原文**
3. 在 Grokbot「业务顾问」查 1–2 条客户或竞品的公开资料，存进 `知识库/99_其他/`，写明**来源网址和查询日期**

### C · 邮件助理 → 日报 + 定时任务（35 分钟 · WorkBuddy）

1. 连接器 → 邮箱 → 扫码连上课前注册的 **QQ 测试邮箱**（已有 13 封测试邮件）
2. 发 `邮件助理提示词.md` 里的提示词，先**手动跑一次**
3. 分类或摘要不对就改提示词再跑，直到全对
4. 建定时任务：**每天 08:30** 推送到企业微信机器人（绑定后先给机器人发一条消息）

✓ 检查：可疑邮件**没点链接**；所有回复都是**草稿**

### D · FAQ 素材 → `FAQ素材.md`（20 分钟 · Codex）

1. 说：「从 知识库/ 里挑出客户最常问的 5 个问题，按 FAQ素材模板.md 的格式写进 知识库/FAQ素材.md」
2. 问题用客户原话（看邮件和聊天记录），答案**先结论、后依据**

✓ 检查：**没有一个数字**是知识库里找不到的

## 示例指令（B 步）

```markdown
角色：你是我的业务资料助理
目标：回答下面 3 个客户问题，每个答案一段话，附出处
输入：知识库/（只用这里的内容）；业务卡片.md
约束：不用你自己的常识补充；两份资料说法冲突时，列出两边并标「待确认」；找不到就写「知识库里没有」
验收：每个答案都有「文件名 + 段落或行号」；数字和原文一致
节奏：先列出你打算引用哪几份文件，我确认后再回答

问题：
1. ____
2. ____
3. ____
```
