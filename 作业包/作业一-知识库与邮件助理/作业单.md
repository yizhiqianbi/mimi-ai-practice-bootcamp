# 作业一｜业务知识库 + 邮件助理

约 105 分钟，含 15 分钟茶歇（Day 1 14:25–16:25）｜课件第 29 页｜之后 16:25–17:00 小组互查

图文教程（每一步的截图、可复制的指令和参考结果）：`作业包/教程/作业一教程.html`

## 目标

1. 一套业务知识库：统一命名、有总索引，问它问题能答出来并带出处
2. 一个邮件助理：每天 08:30 自动分类、摘要、起草回复，推到企业微信，**只起草不发送**
3. 一份 `知识库/FAQ素材.md`：客户最常问的 5 个问题和答案，作业四网站直接用

## 用什么资料

- 带了自己资料的：复制到业务文件夹的 `资料/`
- 没带资料的：复制 `示例资料_木序办公家具_虚构/` 里的 30 个文件到 `资料/`，邮件用 `示例邮件/`

示例资料是一家虚构的办公家具公司。里面跟真实公司一样乱：有重复文件、新旧版本、两份文件说法对不上，还有跟业务无关的私人文件。你的任务就是让 AI 把这些找出来，而不是直接全部收进知识库。

## 步骤

### A · 整理文件夹（30 分钟）· Codex

1. 在 Codex 里说：「用 organize-files 这个 Skill 整理 资料/」（Skill 在 `.agents/skills/organize-files/`）
2. 它会先给你盘点表和问题清单（重复、过期、冲突），**你来决定**以哪份为准
3. 确认后它把文件归类、改名、复制到 `知识库/`，生成 `知识库/总索引.md`

✓ 检查：索引最后的总数核对能对上（资料 N 个 = 保留 + 作废 + 打不开）；随手抽 3 条摘要，打开原文对一下数字

### B · 知识库问答（20 分钟）· Codex + Grokbot

1. 写下 3 个客户真的问过你的问题，在 Codex 里问：「只根据 知识库/ 回答，每个答案写出处（文件名 + 位置），找不到就说找不到」
2. 打开出处文件，核对答案
3. 在 Grokbot「业务顾问」里查 1–2 条客户或竞品的公开资料，存进 `知识库/99_其他/`，文件里写清楚来源网址和查询日期

✓ 检查：每个答案都能找到出处；出处里的原文和答案一致

### C · 邮件助理（35 分钟）· WorkBuddy

1. WorkBuddy → 连接器 → 邮箱 → 扫码连上课前注册的 QQ 测试邮箱（讲师已经往里面发了 13 封测试邮件）
2. 先手动跑一次：把 `邮件助理提示词.md` 里的提示词发给 WorkBuddy，看结果
3. 不对就改提示词，再跑，直到分类和摘要都对
4. 跑通后建定时任务：每天 08:30，推送到企业微信机器人（绑定后先给机器人发一条消息）

✓ 检查：13 封都出现在日报里；摘要里的订单号、日期、人数没有写错；可疑邮件被单独标出、没有点链接；所有回复都是草稿

### D · FAQ 素材（20 分钟）· Codex

1. 在 Codex 里说：「从 知识库/ 里挑出客户最常问的 5 个问题，按 FAQ素材模板.md 的格式写进 知识库/FAQ素材.md」
2. 问题用客户的原话（看邮件和聊天记录里客户怎么问），答案先给结论再给依据

✓ 检查：5 个答案每个都有出处；没有一个数字是知识库里找不到的

## 示例指令（B 步）

```markdown
角色：你是我的业务资料助理
目标：回答下面 3 个客户问题，每个答案一段话，附出处
输入：知识库/（只用这里的内容）；业务卡片.md
约束：不用你自己的常识补充；两份资料说法冲突时，列出两边并标「待确认」；找不到就写「知识库里没有」
验收：每个答案都有「文件名 + 段落或行号」；数字和原文一致
节奏：先列出你打算引用哪几份文件，我确认后再回答

问题：
1. ____
2. ____
3. ____
```

## 交付

- [ ] `知识库/` 按类别整理好的文件
- [ ] `知识库/总索引.md`
- [ ] 3 个问答（截图或文字），每个带出处
- [ ] 邮件日报一份（截图），定时任务已建好
- [ ] `知识库/FAQ素材.md`
