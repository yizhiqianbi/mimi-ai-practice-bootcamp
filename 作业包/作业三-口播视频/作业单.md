# 作业三｜做一条业务口播视频

约 90 分钟（Day 2 09:25–10:55）｜课件第 35 页

图文教程（每一步的截图、可复制的指令和参考结果）：`作业包/教程/作业三教程.html`

## 目标

1. 一条 60 秒口播视频，作业四嵌进网站首页，也能直接发布
2. 一份口播稿模板，下一条换个选题就能用
3. 标题、封面、发布文案一次准备好

## 步骤

### A · 选钩子，写 60 秒口播稿（25 分钟）· Grokbot + Codex

1. 在「业务顾问」Bot 里发：

```markdown
我要做一条 60 秒口播视频，讲给「____（目标客户）」听，最后让他们「____（行动）」。
请给我 3 个开头钩子，每个 20 字以内，分别用这三种写法：
1. 反常识：说一个客户以为对、其实不对的事
2. 具体数字：用一个我业务里的真实数字开头（从业务卡片里找，没有就标「待确认」）
3. 点名处境：直接说出客户此刻遇到的情况
```

2. 选一个，到 Codex 里说：「用 talk-script 这个 Skill 写口播稿，钩子用 ____，行动指向 ____」
3. 照 `口播稿模板.md` 的五段结构检查，大声读一遍计时，55–65 秒为准

✓ 检查：证据段的数字能在知识库找到出处

### B · 选平台，生成数字人视频（20 分钟）

两条路线选一条，具体按钮见图文教程：

- **路线一：腾讯智影**（国内直连，中文口型自然，大多数学员走这条）：数字人播报 → 先选画布比例 → 选形象 → 粘贴口播稿 → 保存并生成播报 → 合成视频时勾选「超清」
- **路线二：HeyGen**（做出海、要英文版的学员；要能访问海外网站）：Apps → Quick Avatar Video → 选形象和比例 → 粘贴口播稿 → 选普通话音色 → 生成

形象三选一：

- **基础版**：平台授权的公共形象 + 合成配音
- **进阶版**：本人数字分身，开课前 2 天做好（要先签 `肖像与声音授权书.md`；HeyGen 还要本人用摄像头录一段同意声明）
- **兜底**：不用数字人，用产品图、现场照片或录屏 + 合成配音 + 字幕，在剪映里合成

竖版 1080×1920 发短视频，横版 1920×1080 放网站，先做一个。

✓ 检查：视频 55–65 秒、1080P；多音字和数字读对了；素材有授权

### C · 配字幕、剪节奏（30 分钟）

1. 导入剪映：用 Skill 生成的 `.srt` 字幕，或剪映「识别字幕」后对照稿子改错字
2. 删掉停顿和重复，前 3 秒不要放 Logo 和片头
3. 在「证据」段插入真实画面：产品、案例现场、数据截图

### D · 发布文案（15 分钟）· Codex

用 talk-script 生成的发布文案，按 `发布文案模板.md` 检查一遍。

✓ 检查：把视频静音看前 3 秒，字幕能不能让人停下来

| 基础版 | 进阶版 | 兜底 |
|---|---|---|
| 腾讯智影或 HeyGen 的公共形象 + 合成配音 | 本人数字分身（开课前 2 天做好） | 图片或录屏 + 配音 + 字幕，用剪映合成 |

## 两条红线

- 用别人的脸和声音，必须有本人书面授权；明星、网红、客户的形象一律不用
- 发布时按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）标注「AI 生成」；各平台发布页都有这个选项，勾上
