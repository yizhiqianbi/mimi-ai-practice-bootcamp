# 作业三｜做一条业务口播视频

**90 分钟**（Day 2 09:25–10:55）｜课件第 36 页

图文教程：`作业包/教程/作业三教程.html`（每步截图、可复制指令、参考结果）

## 交付物与验收

| 交付物 | 验收标准 | 后面用在 |
|---|---|---|
| **60 秒口播视频** `产出/日期_口播_v1.mp4` | **55–65 秒、1080P**；多音字和数字读对；**静音看前 3 秒**，字幕能让人停下；素材有授权 | 作业四网站首页、直接发布 |
| **口播稿** `产出/日期_口播稿_v1.md` + 字幕 `.srt` | 五段结构齐；证据段的数字**在知识库有出处**；结尾**只有一个行动**，指向网站或表单 | 下一条换选题照用 |
| **发布文案** `产出/日期_发布文案_v1.md` | 标题、封面字、正文齐；按 `发布文案模板.md` 查过；**标注 AI 生成** | 各平台发布 |

## 步骤

### A · 钩子 + 口播稿（25 分钟 · Grokbot + Codex）

1. 在「业务顾问」里发：

```markdown
我要做一条 60 秒口播视频，讲给「____（目标客户）」听，最后让他们「____（行动）」。
请给我 3 个开头钩子，每个 20 字以内，分别用这三种写法：
1. 反常识：说一个客户以为对、其实不对的事
2. 具体数字：用一个我业务里的真实数字开头（从业务卡片里找，没有就标「待确认」）
3. 点名处境：直接说出客户此刻遇到的情况
```

2. 选一个，到 Codex 说：「用 talk-script 这个 Skill 写口播稿，钩子用 ____，行动指向 ____」
3. 对照 `口播稿模板.md` 的五段结构，**大声读一遍计时**，55–65 秒为准

### B · 生成数字人视频（20 分钟）

两条路线选一条，按钮位置见教程：

- **腾讯智影**（国内直连，中文口型自然，**多数人走这条**）：数字人播报 → 先选画布比例 → 选形象 → 粘贴口播稿 → 保存并生成播报 → 合成时勾「超清」
- **HeyGen**（出海、要英文版；需访问海外网站）：Apps → Quick Avatar Video → 选形象和比例 → 粘贴口播稿 → 选普通话音色 → 生成

先做一个比例：**竖版 1080×1920** 发短视频，**横版 1920×1080** 放网站。

### C · 字幕 + 剪节奏（30 分钟 · 剪映）

1. 导入 Skill 生成的 `.srt`，或用「识别字幕」后对照稿子改错字
2. **删停顿和重复**；前 3 秒**不放 Logo 和片头**
3. 证据段插入**真实画面**：产品、案例现场、数据截图

### D · 发布文案（15 分钟 · Codex）

用 talk-script 生成的发布文案，按 `发布文案模板.md` 查一遍。

## 分层

| 基础版 | 进阶版 | 兜底 |
|---|---|---|
| 腾讯智影或 HeyGen **公共形象** + 合成配音 | **本人数字分身**，开课前 2 天做好（先签 `肖像与声音授权书.md`；HeyGen 还要本人录一段同意声明） | 不用数字人：产品图、现场照片或录屏 + 配音 + 字幕，剪映合成 |

## 两条红线

- 用别人的脸和声音，**必须有本人书面授权**；明星、网红、客户的形象一律不用
- 按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）**标注「AI 生成」**，各平台发布页勾上即可
