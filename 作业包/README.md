# 作业包

AI 实战训练营五个现场作业的全部文件，外加一个课后选做的进阶作业。主线「**一个业务，四个作业**」：围绕自己的一个真实业务，从作业零做到作业四，最后合成**一个手机能打开的业务网址**。

## 两天后你手里有什么

| 作业 | 交付物 | 下一步用在 |
|---|---|---|
| 零 | **业务卡片** + **第一个 Skill** | 所有作业的背景；同类工作一句话调用 |
| 一 | **带出处的知识库** + **每天 08:30 的邮件日报** + FAQ 素材 | 网站 FAQ、客服机器人 |
| 二 | **5 页 PPT + 讲稿** + **海报** + 品牌规范 | 网站首屏 |
| 三 | **60 秒口播视频** + 字幕 + 发布文案 | 网站视频区、社媒 |
| 四 | **公开网址** + **线索通知** + SEO/GEO 每周复测 | 名片、社媒主页、获客 |
| 进阶 | **能上线的客服机器人**（50 题答对 ≥ 45） | 客户咨询第一道接待 |

每份作业单开头都是「**交付物与验收**」表：先看要交什么、做到什么程度算过，再按步骤做。

## 示例资料说明

`示例资料_木序办公家具_虚构/` 是一家虚构的东莞办公家具公司，公司名、人名、电话、价格、案例全部是编的，文件里也都标了「虚构示例」。它故意做得和真实公司一样乱：新旧两版产品手册和报价单、一份重复文件、两份说法不同的售后条款、销售话术和会议纪要的折扣对不上、文件名看不出内容的 Word、一份私人便签。作业一的「检查」就是看学员能不能让 AI 把这些找出来。

讲师样例用的是真实企业 HAFYOUNG，事实全部取自已上线的 www.hafyoung-cooling.com；网站上没有的数据（参数、认证、案例、成立年份）都写成「待确认」，没有补编。
