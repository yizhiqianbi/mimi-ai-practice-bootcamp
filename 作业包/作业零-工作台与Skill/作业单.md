# 作业零｜工作台就位 · 业务卡片 · 第一个 Skill

约 70 分钟（Day 1 11:30–12:40）｜课件第 20 页

图文教程（每一步的截图、可复制的指令和参考结果）：`作业包/教程/作业零教程.html`

## 目标

做完你会有三样东西，后面四个作业都在它们上面做：

1. 一个业务文件夹，在 Codex 里能打开，`AGENTS.md` 写好了规矩
2. 一份填满的 `业务卡片.md`
3. 一个你自己的 Skill，用真实资料跑通过一次

## 步骤

### A · 工作台就位（15 分钟）

1. 把 `作业包/工作区模板/我的业务/` 整个复制到电脑上你常用的位置，文件夹改成你的业务名
2. Codex：打开 ChatGPT 桌面应用 → 左上角切到 Codex → 打开这个文件夹 → 权限选 **Ask for approval**
3. 改 `AGENTS.md` 最上面两行：城市 · 行业、一句话
4. WorkBuddy：模式选「日常办公」，新建一个工作空间，指向这个文件夹的副本
5. Grokbot：新建一个 Bot，名字叫「业务顾问」，第一句话用 `业务顾问Bot开场白.md` 里的内容

### B · 写业务卡片（25 分钟）· Grokbot

1. 在「业务顾问」Bot 里发开场白，让它一次只问一个问题
2. 答完 8 项后，让它整理成 `业务卡片.md` 的格式
3. 复制进文件夹里的 `业务卡片.md`，自己再读一遍，把它替你「美化」的地方改回大白话

✓ 检查：每一项都有内容；案例是真实发生过的，有客户类型、做了什么、结果

### C · 写第一个 Skill（20 分钟）· Codex

1. 看业务卡片最后一项「我现在最耗时的一项工作」
2. **基础版**：从 `Skill示例/` 里挑一个最接近的（会议纪要、客户报价、周报），复制到 `.agents/skills/` 下，只改「输入」「输出」「验收」
3. **进阶版**：复制 `.agents/skills/_skill模板/`，从零写，至少 3 个步骤，带输出模板
4. 也可以直接让 Codex 帮你写，用下面这条指令

### D · 拿真实资料跑一次（10 分钟）· Codex

1. 把一份真实资料（一段会议录音转写、一封询价邮件、上周的工作记录）放进 `资料/`
2. 在 Codex 里说：「用 ____ 这个 Skill 处理 资料/____」
3. 按 Skill 里的验收逐条检查。不过关的地方，改 Skill 再跑，不是改结果

✓ 检查：结果能直接用，不用大改

## 示例指令（C 步）

```markdown
角色：你是我的工作流程设计助理
目标：交付一个 Skill，放在 .agents/skills/<英文名>/SKILL.md，用来处理「____（我最耗时的工作）」
输入：业务卡片.md；参考格式 .agents/skills/_skill模板/SKILL.md
约束：步骤里要有「先给我中间结果，确认后再继续」；遇到缺数据写「待确认」，不要编
验收：有输入、步骤、输出格式、验收清单四块；验收清单至少 3 条且能逐条打勾
节奏：先问我 3 个问题了解这项工作，再写
```

## 交付

- [ ] `业务卡片.md`
- [ ] `.agents/skills/<你的 Skill>/SKILL.md`
- [ ] `产出/` 里一份 Skill 跑出来的结果

## 分层

| 基础版 | 进阶版 | 兜底 |
|---|---|---|
| 用 `Skill示例/` 里的模板，只改输入、输出和验收 | 从零写 Skill，含多步骤和输出模板 | 直接用讲师预置的 `工作区模板/`，下载即用 |
