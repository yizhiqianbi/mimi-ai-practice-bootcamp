# 作业零｜工作台就位 · 业务卡片 · 第一个 Skill

**70 分钟**（Day 1 11:30–12:40）｜课件第 20 页

图文教程：`作业包/教程/作业零教程.html`（每步截图、可复制指令、参考结果）

## 交付物与验收

| 交付物 | 验收标准 | 后面用在 |
|---|---|---|
| **业务文件夹** + `AGENTS.md` | Codex、WorkBuddy、Grokbot **各发一句话有回应**；`AGENTS.md` 最上面两行写了城市 · 行业和一句话 | 四个作业都在这里做 |
| **`业务卡片.md`** | 8 项**都有内容**；案例是**真实发生过的**（客户类型、做了什么、结果）；没有被「美化」的空话 | 所有作业的背景 |
| **你的第一个 Skill** `.agents/skills/<名字>/SKILL.md` | 有输入、步骤、输出格式、验收清单四块 | 以后同类工作一句话调用 |
| `产出/` 里**一份跑出来的结果** | 用真实资料跑的；**直接能用，不用大改** | — |

## 步骤

### A · 工作台就位 → 业务文件夹（15 分钟）

1. 把 `作业包/工作区模板/我的业务/` 复制到电脑常用位置，**改成你的业务名**
2. **Codex**：ChatGPT 桌面应用 → 左上角切到 Codex → 打开文件夹 → 权限选 **Ask for approval**
3. 改 `AGENTS.md` 最上面两行：城市 · 行业、一句话
4. **WorkBuddy**：模式选「日常办公」，新建工作空间，指向这个文件夹的副本
5. **Grokbot**：新建 Bot「业务顾问」，第一句话用 `业务顾问Bot开场白.md`

### B · 业务卡片 → `业务卡片.md`（25 分钟 · Grokbot）

1. 在「业务顾问」里发开场白，让它**一次只问一个问题**
2. 答完 8 项，让它整理成 `业务卡片.md` 的格式
3. 复制进文件夹，自己再读一遍，**把美化的地方改回大白话**

### C · 写 Skill → `SKILL.md`（20 分钟 · Codex）

从业务卡片最后一项「**我现在最耗时的一项工作**」下手：

- **基础版**：从 `Skill示例/` 挑最接近的（会议纪要、客户报价、周报），复制到 `.agents/skills/`，**只改输入、输出、验收**
- **进阶版**：复制 `.agents/skills/_skill模板/` 从零写，至少 3 个步骤，带输出模板
- 也可以用下面的示例指令，让 Codex 帮你写

### D · 真实资料跑一次 → 一份结果（10 分钟 · Codex）

1. 放一份真实资料进 `资料/`：会议录音转写、询价邮件、上周工作记录都行
2. 说：「用 ____ 这个 Skill 处理 资料/____」
3. 按 Skill 的验收逐条查。不过关就**改 Skill 再跑，不是改结果**

## 示例指令（C 步）

```markdown
角色：你是我的工作流程设计助理
目标：交付一个 Skill，放在 .agents/skills/<英文名>/SKILL.md，用来处理「____（我最耗时的工作）」
输入：业务卡片.md；参考格式 .agents/skills/_skill模板/SKILL.md
约束：步骤里要有「先给我中间结果，确认后再继续」；遇到缺数据写「待确认」，不要编
验收：有输入、步骤、输出格式、验收清单四块；验收清单至少 3 条且能逐条打勾
节奏：先问我 3 个问题了解这项工作，再写
```

## 分层

| 基础版 | 进阶版 | 兜底 |
|---|---|---|
| 用 `Skill示例/` 的模板，只改输入、输出和验收 | 从零写，多步骤 + 输出模板 | 直接用讲师预置的 `工作区模板/` |
