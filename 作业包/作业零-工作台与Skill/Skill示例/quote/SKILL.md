# 客户报价

## 输入

<!-- 改这里：你的价格表和询价记录放在哪 -->
- 价格表：`知识库/02_产品与价格/____.xlsx`（只用这一份，旧价格表不要用）
- 询价：`资料/` 里的邮件或聊天截图文字
- `业务卡片.md`

## 步骤

1. 从询价里提取：客户是谁、要什么、数量、交付地点、时间要求、预算。缺的项列出来，写成要追问客户的问题。先给我看。
2. 按价格表算价：单价 × 数量，列出运费、安装费、折扣各一行。价格表里没有的项目写「待确认」，不要估。
3. 起草回复：先回答客户最关心的一件事（通常是总价或交期），再列明细，最后一句写清下一步。
4. 按验收自查

## 输出

<!-- 改这里：你们报价单常用的格式 -->
- `产出/日期_报价_客户名.md`：报价明细表 + 回复正文 + 要追问的问题

## 验收

<!-- 改这里 -->
- [ ] 每个单价都能在价格表找到对应行（写出行号）
- [ ] 合计算对了（逐行复核一次）
- [ ] 回复只是草稿，没有发送
- [ ] 有效期、付款方式、交期写清楚了
