# 周报

## 输入

<!-- 改这里：你的工作记录在哪 -->
- `资料/本周/` 里的日报、聊天记录导出、待办截图文字、销售表
- 上周周报：`产出/____`（用来对比上周说要做的事）

## 步骤

1. 列出本周做过的事，按「客户 / 产品 / 团队 / 其他」归类，每条后面写来源文件。先给我看。
2. 对照上周周报的「下周计划」，逐条写完成、部分完成、没做，没做的写原因（原文没有就写「待确认」）
3. 数字单列：成交、线索、收入、支出，只写原文里有的
4. 写下周计划：最多 5 条，每条有负责人
5. 按验收自查

## 输出

<!-- 改这里 -->
`产出/日期_周报.md`

```markdown
# 周报｜YYYY-MM-DD ~ MM-DD
## 一句话
## 本周数字
## 上周计划完成情况
## 本周做了什么
## 问题和需要支持的
## 下周计划
```

## 验收

<!-- 改这里 -->
- [ ] 每个数字都有来源文件
- [ ] 上周计划逐条有交代
- [ ] 下周计划不超过 5 条，每条有负责人
